## 📖 Overview

TuneFlow is a full-stack music streaming web application that provides an interactive music listening experience with secure authentication and modern playback features.

The project is built using React for the frontend, Node.js and Express for the backend, MongoDB for database management, and Redux for state management.

---

## ✨ Features

* 🔐 User Authentication (Signup/Login)
* 🔑 JWT-based Authentication
* ❤️ Add and Remove Favourite Songs
* 🎵 Music Player
* ⏯️ Play / Pause Songs
* ⏭️ Next / Previous Song
* 🔀 Shuffle Playback
* 🔁 Repeat Current Song
* 🔊 Volume Control
* ⚡ Playback Speed Control
* 🔍 Search Songs
* 🎼 Playlist Browsing
* 👤 Edit User Profile
* 📱 Responsive User Interface

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/VaibhaviBanarase/TuneFlow-FullStack-Music-Player.git
```

### Install Backend

```bash
cd backend
npm install
```

### Install Frontend

```bash
cd frontend
npm install
```

### Run Backend

```bash
npm run dev
```

### Run Frontend

```bash
npm run dev
```
